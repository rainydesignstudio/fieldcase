## 1. 来源与取用

- R 保存参考快照、参考项目及其证据；权限、只读和准入取根治理 §1–§2、§4.1，不另设 R 治理文件。消费方发现问题先报告，不就地修改快照。
- 新增或替换参考对象先明确来源、固定版本或提交（适用时）、本地范围、用途、许可事实及实际读取入口；用户准入并授权后，由有权限维护者落实正文与索引。
- 每项取用方式写清上述来源定位及读取限制；内容较多时复用已有局部索引，只按命中读取。上游发生变化不使已登记快照自动更新。
- 参考证据只证明其实际覆盖范围；未运行的源码、未取得的原文和未核实的推断须分别说明，不把参考实现自动当作本实例规范。
- 文件登记实际 B；目录填 —，通过局部索引或明确路径继续定位。不把目录入口解释为整读许可，也不把来源链接当作本地快照已具备。

## 3. 维护

本区启用 Git 时，本区对 R 的跟踪范围限 R 总 INDEX，参考快照正文留在仓外。层版本、内容状态和固定定位按实际来源记录。没有 Git 时说明历史快照能力，不捏造提交或标签。实际消费来源只在消费区 HANDOFF 登记，不在此另列消费者。

本索引负责 R 的入口、来源定位和读取说明；复核触发：参考来源、快照范围、用途、入口、读取方式或仓库选择变化。索引维护不扩大参考内容的写入权限。
